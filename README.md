# GIVEN-NETFLIX

A responsive front-end clone of the Netflix landing page built using HTML and CSS. This project recreates the modern Netflix homepage design, focusing on layout structure, responsive design, and clean user interface styling.

---

## 🌐 Project Overview

This project was created as a front-end practice project to improve web development skills in:

- Responsive web design
- Layout structuring
- UI recreation
- HTML & CSS styling
- Modern landing page development

The website replicates the visual appearance of Netflix’s homepage, including the hero section, navigation bar, buttons, and footer.

---

## ✨ Features

- Responsive Netflix-inspired layout
- Hero section with background image
- Navigation bar
- Call-to-action buttons
- Clean footer design
- Mobile-friendly structure
- Modern UI styling

---

## 🛠 Technologies Used

- HTML5
- CSS3
